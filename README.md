# Стеклобит

Страница с атмосферными звуками и битом из звуков стекла поверх анимации: стеклянные мозаики с драконом и тигром в деревянных рамках-досочках.

## Что внутри

| Файл | Что это |
| --- | --- |
| `index.html` | Сама страница: микшер атмосферных звуков, 16-шаговый секвенсор, фон. Всё в одном файле, включая векторный фон и звуки, вырезанные из ролика. |
| `animation.mp4` | Фоновое видео: бесшовный цикл 29 с, 960×640, 7,5 кадра в секунду как у исходного стоп-моушена (H.264 + AAC, около 1,4 МБ), вырезан из [ролика на YouTube](https://youtu.be/bjlWsR_b4HE). |
| `scene.svg` | Векторная версия анимации, работает и сама по себе: стоп-моушен из 10 поз туда-обратно, цикл 2,4 с. |
| `tools/scene_gen.py` | Скрипт, который генерирует `scene.svg` (Python 3, без зависимостей). |
| `tools/tiger_shards.json` | Осколки тигра, обведённые по фотографии оригинальной мозаики. |
| `tools/trace_tiger.py` | Обводка тигра по фото (OpenCV): так получен `tiger_shards.json`. |

## Как устроено

- **Фон.** По умолчанию показан векторный рисунок, кнопка «Показать видео» переключает на ролик. Видео начинает грузиться только по этой кнопке или по каналу «Звук из видео», поэтому страница открывается быстро. В альбомной ориентации кадр подбирается так, чтобы обе рамки с героями были видны целиком.
- **Звуки секвенсора.** Строки «Звон», «Бас», «Хруст», «Динь» и «Гул» — это короткие сэмплы из звуковой дорожки ролика. «Лёд» и звуки атмосферы синтезируются через Web Audio.
- **Пресет «Как в ролике»** повторяет рисунок бита из видео (80 BPM).
- **Анимация и бит.** Пока играет секвенсор, анимация идёт по часам звука: на 80 BPM ровно как в ролике (новая поза каждые 4 кадра), быстрее или медленнее вместе с темпом. Когда секвенсор остановлен, анимация идёт в своём темпе.

## Запуск

Откройте `index.html` в браузере, `animation.mp4` должен лежать рядом. Канал «Звук из видео» надёжнее всего работает, когда страница открыта через веб-сервер или GitHub Pages.

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`. Страница появится по адресу `https://tastex.github.io/steklobit/`.

## Обновление векторного фона

```
python3 tools/scene_gen.py
```

Скрипт пишет `scene.svg` в текущую папку. В `index.html` та же сцена встроена прямо в разметку (`<svg id="vec">`), поэтому после изменений её нужно перенести и туда.
