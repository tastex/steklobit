# Стеклобит

Страница с атмосферными звуками и битом из звуков стекла поверх анимации: стеклянные мозаики с драконом и тигром в деревянных рамках-досочках.

## Что внутри

| Файл | Что это |
| --- | --- |
| `index.html` | Сама страница: микшер атмосферных звуков, 16-шаговый секвенсор, фон. Всё в одном файле, включая первый кадр ролика (показывается сразу) и звуки, вырезанные из ролика. |
| `animation.mp4` | Фоновое видео: бесшовный цикл 29 с, 960×640, 7,5 кадра в секунду как у исходного стоп-моушена (H.264 + AAC, около 1,4 МБ), вырезан из [ролика на YouTube](https://youtu.be/bjlWsR_b4HE). |

## Как устроено

- **Фон.** Сразу показан первый кадр ролика (webp прямо в странице), а само видео тихо подгружается после загрузки страницы и включается, как только готово, без индикатора. Видео берётся целиком и играет из памяти, поэтому работает и там, где хостинг не отдаёт файл частями. Если браузер не дал запустить видео сам (например, режим энергосбережения на iPhone), оно стартует с первым касанием. В альбомной ориентации кадр подбирается так, чтобы обе рамки с героями были видны целиком.
- **Звуки секвенсора.** Строки «Звон», «Бас», «Хруст», «Динь» и «Гул» — это короткие сэмплы из звуковой дорожки ролика. «Лёд» и звуки атмосферы синтезируются через Web Audio.
- **Длина дорожки.** Кнопкой «Добавить такт» паттерн растёт до 8 тактов по 16 шагов, новый такт начинается копией последнего. Пресеты, «Случайно» и «Очистить» работают на всю длину, ссылка и WAV учитывают все такты.
- **Пресет «Как в ролике»** повторяет рисунок бита из видео (80 BPM).
- **Скачать бит.** Кнопка под сеткой сводит бит в WAV вместе с эхом, свингом, громкостью, заглушёнными строками и включёнными звуками атмосферы (кроме «Звука из видео»). Длина файла — 4–32 такта (не меньше длины дорожки, целыми проходами) плюс хвост эха. Сведение идёт через `OfflineAudioContext` по той же цепочке звука, что и в живом проигрывании, поэтому быстрее реального времени. В артефакте на claude.ai файл сохраняется в zip-архиве (WAV внутри), там другие форматы не разрешены.
- **Поделиться ссылкой.** Паттерн и настройки записываются в адрес после `#`, например `#t=80&sw=0&e=35&v=80&g=...x....-xoxo...&a=rain.50` (`t` — темп, `sw` — свинг, `e` — эхо, `v` — громкость, `g` — шесть строк сетки по 16 шагов на такт, где `x` громкий удар, `o` тихий, `.` пусто; `m` — заглушённые строки, `a` — звуки атмосферы с громкостью). При открытии такой ссылки бит восстанавливается, а атмосфера включается с первым нажатием ▶. Из артефакта ссылка ведёт на GitHub Pages.
- **Видео и бит.** Пока играет секвенсор, видео идёт в его темпе: на 80 BPM как в ролике, быстрее или медленнее вместе с темпом.

## Запуск

Откройте `index.html` в браузере, `animation.mp4` должен лежать рядом. Канал «Звук из видео» надёжнее всего работает, когда страница открыта через веб-сервер или GitHub Pages.

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`. Страница появится по адресу `https://tastex.github.io/steklobit/`.
